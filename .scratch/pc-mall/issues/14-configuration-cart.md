## Acceptance criteria

- [x] 登录用户主动提交真实商品配置，服务端重验完整性、F03核心通过、当前可售状态、价格和库存。
- [x] 七类基础或合法八类配置可整组入车，每类仅一个销售SKU；按2026-11-11用户确认保留内存1～4根，其他类别各一个单位；不完整或未知不得通过。
- [x] 任一明细失败时整个配置组回滚，界面不显示部分成功组，不锁价或预占库存。
- [x] 单品与配置组、多个不同配置组可共存，同SKU归属分别保留并汇总已有购物车需求。
- [x] 完全相同类别/SKU/数量的配置去重，名称、来源和价格差异不绕过去重；重复请求不能多建组。
- [x] 展示组及明细并支持整组删除；拒绝在购物车中拆组或单独更改组内数量。
- [x] 验证第八项写入失败、重复并发入车、伪造通过字段、聚合缺货及游客拦截。
