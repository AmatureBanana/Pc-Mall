## Acceptance criteria

- [x] 用户可查看本人订单列表、详情、成交单价和分组；其他用户访问被拒绝，历史展示不联查覆盖快照。
- [x] 仅订单所有者能对PENDING_PAYMENT且服务端now早于expiresAt的订单执行模拟支付。
- [x] 支付按订单成交金额和状态处理，转PAID并记录必要时间/结果，不调用真实支付。
- [x] 支付不第二次扣减可售库存，重复与并发请求不产生重复有效支付或库存副作用。
- [x] 恰好到期或过期时支付被拒绝，不能因扫描尚未运行而放行；非法状态有明确反馈。
- [x] 通过真实MySQL、可控时钟和浏览器验证正常支付、越权、重复提交、截止边界与查询隔离。
