## Acceptance criteria

- [x] ADMIN 可修改合法正数 CNY 售价，精确到两位小数，用户查询读取更新后的价格。
- [x] 可查询并受控调整非负整数可售库存，填写原因；预占关系不能被直接覆盖。
- [x] 库存变更采用事务、固定顺序行锁与条件保护，不产生负数或丢失并发调整。
- [x] 价格及库存变更的操作者、原因与前后值可追溯，审计失败导致应原子处理的变更回滚。
- [x] 当前商品与参数变更可被后续重验识别，历史成交快照不通过商品更新链路改写。
- [x] 真实 MySQL 验证并发调整、非法金额、负库存和审计故障；页面展示最新结果。
