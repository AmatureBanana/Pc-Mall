## Acceptance criteria

- [x] ADMIN 可维护 CPU/GPU 有效评分数据及来源、基准版本、采样条件、原始值和映射版本。
- [x] 采用固定版本 Blender 渲染参考，型号与变体匹配有依据；缺失、不可靠或混合口径数据不得补默认有效分。
- [x] CPU 0/50/200/450/800、GPU 0/500/2000/4500/8000 分别映射到 0/25/50/75/100，相邻插值并封顶100。
- [x] 容量口径与固定 RAM/SSD 评分节点一致，SSD 1TB=1000GB；原始单位可追溯。
- [x] 提供足以验证办公核显、游戏独显及内容创作的真实候选，售价和库存明确为商城演示数据。
- [x] 数据包记录来源、校验值与许可归因；评分变更影响后续读取并留痕，不能在线任意改冻结权重。
- [x] 验证后台维护、缺评分处理、插值边界与版本稳定性；负面测试样本与正常商品分开。
