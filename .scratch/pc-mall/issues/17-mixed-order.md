## Acceptance criteria

- [x] 一笔订单可包含普通单品和多个完整配置组，组内不得部分选择或拆分结算。
- [x] 下单对每组重新验证F02完整性和当前F03全部适用P0；客户端旧成功或来源标签不能绕过。
- [x] 同SKU跨单品与不同配置组聚合库存总量，但明细和快照继续保留各组归属。
- [x] 普通单品99件上限不套到聚合总量；验证99件单品加不同配置中的同SKU在库存足够时合法。
- [x] 任何一组缺件、未知、不兼容、下架、缺货或变价未确认，整个选中订单不部分成功。
- [x] 订单、组快照、库存与购物车清理沿用同一事务，失败时各组和其他项均保留。
- [x] 真实数据库和浏览器覆盖混合成交、聚合缺货、伪造拆组、写入故障和历史快照稳定。
