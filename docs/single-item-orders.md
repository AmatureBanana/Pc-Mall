# 单品原子下单与成交快照

任务16新增 V23 的订单、成交明细和持久化幂等记录，复用 Session、CSRF、购物车报价与 `ProductInventory`。任务17在同一服务内扩展[配置组混合下单](mixed-orders.md)；支付、取消、超时释放和订单列表由后续任务实现。

## 下单与结果接口

`POST /api/orders` 仅接受：

```json
{"revision":2,"itemIds":[11,12],"configurationIds":[],"quoteToken":"预结算返回的64位指纹","requestKey":"order-唯一请求标识"}
```

身份只取 Session。`revision` 是本人购物车内容修订；选择是服务端单品行ID，任务17起也可提交完整组ID，不接收客户端数量、SKU、价格、金额或所属用户。JSON重复字段、额外字段、重复或非法ID、缺字段均400。请求标识沿用8～64位字母数字及 `._:-`，区分大小写。

用户核对预结算明细并主动确认后，提交其报价指纹；下单仍重新核验本人购物项、内容修订、数量、当前可售状态、库存与现价。商品再次变化409 `PRICE_CONFIRMATION_REQUIRED`，须重新预结算和确认。购物车内容过期409 `CART_CONFLICT`；不存在或他人项404；不可售/不足409 `CART_SELECTION_INVALID`。任务17起允许完整配置组，规则见混合下单契约。

成功200返回 `data`：`orderNumber`、`status=PENDING_PAYMENT`、`currency=CNY`、两位小数字符串 `total`、UTC `createdAt`、`paymentDeadline` 以及 `items`；任务17另返回 `configurations` 组快照列表，单品订单为空数组。截止为服务端创建时刻加30分钟，时间精确到微秒。明细保存成交 `productId`、`sku`、`name`、`model`、`category`、`price`、`quantity`、`amount`、`configurationId`（单品为null），后续商品变更不改写快照。

`GET /api/orders/{orderNumber}` 读取本人订单及快照，未知与他人订单都404。全部订单响应经购物车包的错误映射返回，成功和业务/数据库失败均 `Cache-Control: no-store`。未登录401，POST缺CSRF403；数据库故障503。

## 原子性、锁和幂等

订单事务采用 `READ_COMMITTED`，依次锁本人购物车、幂等记录、预占头，再按商品ID升序取得所有选中商品的写锁。隔离级别避免不存在的幂等键产生跨用户索引间隙锁；所有影响成交的可变内容仍由显式行锁保护。购物车清理持有同一购物车锁，管理员写入使用同一商品行锁及库存条件更新。

库存服务新增带最终验证回调的 `reserve` 重载：取得全部商品写锁后、任何库存变化前调用验证；复用原预占逻辑及事务，不先持有商品共享锁再升级。验证本次选中单品，任务17起同时验证选中完整组；未选中项不阻断或被删除。订单头、所有成交明细、组快照、预占及明细、选中项删除、购物车修订和幂等记录均在一个事务中提交或回滚。订单号由UUID生成并受主键唯一约束，预占引用等于订单号。

幂等记录以用户、`CREATE_ORDER`操作与请求键唯一，指纹绑定用户、操作、内容修订、排序后的选中单品ID与报价指纹；任务17的混合请求另绑定排序后的组ID，纯单品保留原指纹格式。成功后同内容重试先返回原订单，不再核验已经清除的购物项、不再预占；同键不同内容409 `IDEMPOTENCY_KEY_REUSED`。失败事务不留下成功记录，可以使用原键重试。

浏览器从购物车预结算确认后主动“创建订单”，成功跳到 `/#order/{orderNumber}`，可刷新读取本人结果。请求结果未知时保留原内容和原键，“重试确认上次下单”可在购物车已被清空后找回同一订单；身份变化清理在途请求与重试上下文。该上下文仅保留在当前页面运行期，关闭或重新加载页面后不保留，后续订单列表交任务18。

重试若收到服务端在成功幂等查询之后才会返回的 `CART_CONFLICT`、`PRICE_CONFIRMATION_REQUIRED`、`CART_SELECTION_INVALID` 或 `CART_ITEM_NOT_FOUND`，可以确认本次内容没有成交，释放旧尝试并显示具体原因，允许重新报价确认后下单。认证、CSRF或传输失败不能证明先前没有成交，仍保留未知语义。共享HTTP错误保留服务端业务代码，仅订单重试消费这些恢复信号。

验证记录见[任务16](evidence/task-16.md)。未增加依赖、复制外部代码或导入新数据。
